- `*` für *kursiv*
- `**` für **fett**
- `***` für kursiv und fett
- shift + cmd + v zum Markdown Preview
- `[Linktext](https://github.com)`
- `![Alt-Text](bild.png)`

- Tabellen erstellen mit (opt+7) | und -
- cmd + k, dann v öffnet preview neben editor
- [x] erledigt
